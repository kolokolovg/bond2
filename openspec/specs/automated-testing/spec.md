# automated-testing Specification

## Purpose
Гарантирует, что поведение приложения проверяется автоматическими тестами различных видов, а качество самих тестов измеряется покрытием и мутациями.

## Requirements

### Requirement: Модульные тесты в стандартной сборке
Задача `check` SHALL запускать все модульные тесты и падать при любом провалившемся тесте.

#### Scenario: Все тесты проходят
- **WHEN** выполняется `./gradlew check` на корректном коде
- **THEN** тесты запускаются и сборка завершается успешно

#### Scenario: Тест падает
- **WHEN** один тест не проходит
- **THEN** `./gradlew check` завершается с ошибкой и указывает упавший тест

### Requirement: Property-based тесты
Проект SHALL содержать property-based тесты для доменной логики, проверяющие инварианты на множестве сгенерированных входов.

#### Scenario: Нарушение инварианта
- **WHEN** сгенерированный вход нарушает инвариант
- **THEN** тест падает и сообщает минимальный воспроизводящий пример

### Requirement: Порог покрытия
Сборка SHALL формировать отчёт покрытия и падать, если покрытие строк ниже заданного порога.

#### Scenario: Покрытие ниже порога
- **WHEN** покрытие ниже порога
- **THEN** `./gradlew check` завершается с ошибкой, отчёт доступен в каталоге сборки

### Requirement: Мутационное тестирование
Проект SHALL предоставлять отдельную задачу мутационного тестирования, падающую при доле убитых мутантов ниже порога.

#### Scenario: Выжившие мутанты сверх допустимого
- **WHEN** доля убитых мутантов ниже порога
- **THEN** задача завершается с ошибкой и формирует отчёт с выжившими мутантами

### Requirement: UI-тесты без дисплея
Проект SHALL позволять запускать тесты, использующие JavaFX, в окружении без графического дисплея через флаг сборки `-Pheadless=true`. Флаг SHALL действовать на задачи `test` и `pitest`. Без флага тесты SHALL выполняться на реальном дисплее.

#### Scenario: Тесты в окружении без дисплея
- **WHEN** выполняется `./gradlew check -Pheadless=true` без дисплея
- **THEN** тесты, использующие JavaFX, запускаются и проходят

#### Scenario: Мутационное тестирование без дисплея
- **WHEN** выполняется `./gradlew pitest -Pheadless=true` без дисплея
- **THEN** UI-тесты внутри мутационного прогона запускаются без ошибки инициализации дисплея

#### Scenario: Запуск без флага
- **WHEN** тесты запускаются без `-Pheadless`
- **THEN** используется обычный графический тулкит
