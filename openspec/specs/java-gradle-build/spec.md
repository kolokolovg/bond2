# java-gradle-build Specification

## Purpose
Определяет воспроизводимую сборку и запуск приложения на Java 21 с помощью Gradle, независимо от установленного на машине JDK.

## Requirements

### Requirement: Сборка на Java 21
Сборка SHALL компилировать и запускать код на Java 21 независимо от версии JDK, на которой запущен сам Gradle.

#### Scenario: Компиляция на чистой машине
- **WHEN** разработчик выполняет `./gradlew build` на машине без Java 21
- **THEN** необходимый JDK 21 подтягивается автоматически и сборка завершается успешно

#### Scenario: Версия байткода
- **WHEN** сборка завершена
- **THEN** скомпилированные классы имеют целевую версию Java 21

### Requirement: Воспроизводимость через Gradle Wrapper
Проект SHALL содержать Gradle Wrapper с зафиксированной версией, совместимой с Java 21.

#### Scenario: Запуск без установленного Gradle
- **WHEN** разработчик запускает `./gradlew --version` на машине без Gradle
- **THEN** загружается зафиксированная версия и команда завершается успешно

### Requirement: Запуск приложения
Приложение SHALL запускаться командой `./gradlew run` и открывать главное окно. Аргументы командной строки SHALL игнорироваться; консольного режима нет.

#### Scenario: Успешный запуск
- **WHEN** выполняется `./gradlew run`
- **THEN** открывается главное окно, а после его закрытия процесс завершается с кодом 0

#### Scenario: Аргументы командной строки
- **WHEN** приложению переданы любые аргументы
- **THEN** они игнорируются, приложение запускается как обычно

### Requirement: Устойчивость конфигурации к отсутствию свойств
Отсутствие опционального свойства сборки (пороги проверок) SHALL NOT мешать конфигурации: применяются зафиксированные значения по умолчанию, любые задачи конфигурируются и выполняются. Значение по умолчанию SHALL совпадать с закоммиченным значением свойства.

#### Scenario: Свойство порога отсутствует
- **WHEN** свойство порога покрытия или мутаций не задано в свойствах проекта
- **THEN** конфигурация сборки завершается успешно, применяется значение по умолчанию

#### Scenario: Свойство задано
- **WHEN** свойство порога задано
- **THEN** применяется заданное значение, как до изменения

### Requirement: Версии инструментов в каталоге версий
Версии внешних инструментов сборки и верификации (OpenJML, pitest, плагин мутационного тестирования, анализатор дефектов) SHALL быть зафиксированы в каталоге версий проекта в единственном месте. Свойство командной строки с тем же именем SHALL переопределять значение каталога для инструмента верификации; ключ кэша CI SHALL учитывать каталог версий.

#### Scenario: Обновление версии инструмента
- **WHEN** версия инструмента меняется в каталоге версий
- **THEN** сборка использует новую версию без правок скрипта сборки, кэш CI инвалидируется

#### Scenario: Переопределение свойством
- **WHEN** версия OpenJML задана свойством командной строки
- **THEN** используется она вместо значения из каталога версий
