# app-settings Specification

## Purpose
Определяет пользовательские настройки расположения БД (путь к файлу, автооткрытие при запуске), их сохранение между запусками и окно редактирования настроек.

## Requirements

### Requirement: Настройки расположения БД
Система SHALL поддерживать настройки: путь к файлу БД и флаг автооткрытия БД при запуске. Пустой путь SHALL означать путь по умолчанию (`DataDirectory.databaseFile()`). Значение флага по умолчанию — «включено».

#### Scenario: Первый запуск без файла настроек
- **WHEN** файла настроек нет
- **THEN** используются путь по умолчанию и автооткрытие включено

#### Scenario: Заданный путь
- **WHEN** в настройках указан путь к файлу БД
- **THEN** именно этот файл используется при открытии БД

### Requirement: Сохранение настроек
Система SHALL сохранять настройки в файле конфигурации в пользовательском каталоге и восстанавливать их при следующем запуске. Повреждённый или нечитаемый файл настроек SHALL NOT мешать запуску: применяются значения по умолчанию (см. «Восстановление испорченного файла настроек»).

#### Scenario: Перезапуск
- **WHEN** пользователь сохранил настройки и перезапустил приложение
- **THEN** сохранённые значения применены

#### Scenario: Повреждённый файл настроек
- **WHEN** файл настроек не удаётся разобрать
- **THEN** приложение запускается со значениями по умолчанию

### Requirement: Восстановление испорченного файла настроек
Система SHALL копировать испорченный файл настроек в `settings.properties.bad-<yyyyMMdd-HHmmss>` рядом с ним (при совпадении имени добавляется числовой суффикс), записывать на его место значения по умолчанию и применять их. Сбой копирования или записи не мешает запуску и пишется в лог.

#### Scenario: Файл настроек не читается
- **WHEN** файл настроек не удаётся разобрать
- **THEN** его копия сохранена как `settings.properties.bad-<метка времени>`, файл настроек содержит значения по умолчанию, приложение запускается с ними, пользователю показано предупреждение с путём к копии

#### Scenario: Копию создать не удалось
- **WHEN** копирование или запись значений по умолчанию завершились ошибкой
- **THEN** приложение запускается со значениями по умолчанию, ошибка записана в лог, пользователю показано предупреждение без пути к копии

### Requirement: Признаки испорченного файла настроек
Испорченным SHALL считаться файл настроек, который не читается или содержит значения, не разбираемые как путь к БД (только абсолютный) и флаг `true`/`false`. Отсутствие файла, ключей и пустой путь повреждением SHALL NOT считаться.

#### Scenario: Относительный путь к БД
- **WHEN** в файле настроек путь к БД относительный
- **THEN** файл копируется и сбрасывается, как повреждённый, пользователю показано предупреждение

#### Scenario: Неверное значение флага
- **WHEN** флаг автооткрытия равен значению, отличному от `true` и `false`
- **THEN** файл копируется и сбрасывается, как повреждённый, пользователю показано предупреждение

#### Scenario: Первый запуск не считается повреждением
- **WHEN** файла настроек нет или в нём нет части ключей
- **THEN** копия не создаётся, предупреждение не показывается, отсутствующие значения берутся по умолчанию

### Requirement: Предупреждение о сбросе настроек
После сброса испорченного файла настроек система SHALL показать пользователю предупреждение, что настройки были повреждены и сброшены, с путём к копии (если она создана).

#### Scenario: Предупреждение после сброса
- **WHEN** испорченный файл настроек был сброшен при запуске
- **THEN** пользователю показано предупреждение о сбросе; путь к копии указан, если копия создана

### Requirement: Окно настроек
Система SHALL предоставить отдельное модальное окно настроек с полем пути к файлу БД, кнопкой выбора файла, флажком «Открывать базу при запуске» и кнопками «Сохранить» и «Отмена».

#### Scenario: Сохранение
- **WHEN** пользователь изменил значения и нажал «Сохранить»
- **THEN** настройки записаны в файл, окно закрыто

#### Scenario: Отмена
- **WHEN** пользователь нажал «Отмена» или закрыл окно
- **THEN** настройки не изменены

#### Scenario: Недопустимый путь
- **WHEN** путь не является допустимым путём к файлу (например, указывает на существующий каталог)
- **THEN** окно показывает ошибку, настройки не сохраняются
