## ADDED Requirements

### Requirement: Распознавание пустого и чужого файла
При открытии существующего файла система SHALL отличать пустой файл (0 байт) и файл SQLite без истории миграций приложения от БД приложения. Пустой файл SHALL инициализироваться актуальной схемой как новая БД, без предложения миграции. Файл SQLite, содержащий таблицы, но не имеющий истории миграций приложения, SHALL отклоняться ошибкой «не база данных приложения»; файл при этом SHALL NOT изменяться и миграция SHALL NOT предлагаться. Файл, не являющийся SQLite, отклоняется ошибкой чтения схемы, как и ранее.

#### Scenario: Пустой файл
- **WHEN** открывается существующий файл размером 0 байт
- **THEN** он инициализируется актуальной схемой, БД открывается без вопроса о миграции

#### Scenario: Чужая база SQLite
- **WHEN** открывается SQLite-файл с таблицами, но без истории миграций приложения
- **THEN** открытие завершается ошибкой «не база данных приложения», файл не изменён, миграция не предлагается

#### Scenario: Пустая база SQLite без таблиц
- **WHEN** открывается корректный SQLite-файл без таблиц
- **THEN** он обрабатывается как пустой: инициализируется актуальной схемой

#### Scenario: База приложения
- **WHEN** открывается БД с историей миграций приложения
- **THEN** поведение прежнее: актуальная схема открывается, устаревшая требует миграции, новее приложения отклоняется
