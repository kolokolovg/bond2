# Design

## Context

См. proposal.md. `SettingsStore.load()` возвращает `Settings` и пишет сбой в лог; `DatabaseController.attempt(file, defaultPath)` создаёт БД, если файла нет и путь по умолчанию. Резервная копия: `Database.createBackup` с именем `<файл>.bak-<yyyyMMdd-HHmmss>`.

## Goals / Non-Goals

**Goals:**
- Пользователь узнаёт о сбросе настроек.
- Сброс не приводит к тихому созданию пустой БД.
- Копии не конфликтуют по имени и не копятся бесконечно.

**Non-Goals:**
- Настройки хранения копий в интерфейсе.
- Изменение критериев «испорченного» файла.

## Decisions

1. **`SettingsStore.load()` возвращает результат с признаком сброса** (`LoadResult(Settings settings, @Nullable Path badCopy, boolean recovered)`), а не бросает и не пишет только в лог. Альтернатива — отдельный метод `wasRecovered()` с состоянием в хранилище: хуже тестируется и хранит скрытое состояние.
2. **Контроллер запоминает `recovered` и в `openOnStartup()` сначала показывает `dialogs.warn`, затем вызывает открытие с запретом автосоздания.** Запрет передаётся параметром в `attempt`, а не флагом в настройках: сброс касается только этого запуска. Альтернатива — писать в настройки «путь неизвестен»: смешивает состояние и конфигурацию.
3. **Автосоздание запрещено только после сброса.** Первый запуск без файла настроек создаёт БД, как сейчас.
4. **Уникальное имя копии: суффикс `-1`, `-2`…, как в `SettingsStore.badCopyPath`.** Миллисекунды не гарантируют уникальность, суффикс — гарантирует.
5. **Очистка после успеха: оставить 3 копии по шаблону `<имя>.bak-<yyyyMMdd-HHmmss>(-N)?`, сортировка по метке времени в имени, затем по суффиксу.** Файловое время не используем: копирование сохраняет не всегда. Ошибка удаления старой копии пишется в лог и миграцию не ломает.

## Risks / Trade-offs

- [Предупреждение блокирует запуск модальным окном] → Показывается после показа главного окна, как остальные диалоги.
- [Старые копии удалены, а нужна была именно старая] → Хранится три последние и копия, сделанная перед текущей миграцией; число копий вынесено в константу.
- [Пользовательский файл `*.bak-…` по тому же шаблону будет удалён] → Шаблон строгий (метка времени), чистятся только файлы с именем исходной БД.
