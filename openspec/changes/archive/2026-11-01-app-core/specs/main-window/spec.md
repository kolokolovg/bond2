# Spec Delta

## REMOVED Requirements

### Requirement: Запуск второго экземпляра
**Reason**: Требование дублировало спецификацию `single-instance` (сообщение о уже
запущенном приложении и завершение нового экземпляра уже покрыты её сценариями «Второй
запуск» и «Не удалось создать файл блокировки»). Порядок стартового конвейера — окно и БД
только после блокировки — теперь описывает новая capability `app-lifecycle`.
**Migration**: Видимое поведение не меняется. За сообщение и завершение второго
экземпляра отвечает `single-instance`, за порядок шагов при запуске — `app-lifecycle`
(требование «Стартовый конвейер»).

### Requirement: Закрытие БД при внешнем завершении процесса
**Reason**: Поведение относится к завершению процесса в целом, а не к главному окну;
вместе с переносом композиции приложения в ядро требование переезжает в новую capability
`app-lifecycle`.
**Migration**: Требование без изменений формулировок перенесено в `app-lifecycle` под тем
же именем «Закрытие БД при внешнем завершении процесса», сценарии сохранены.
