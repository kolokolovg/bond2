## Why

Путь к файлу БД сейчас жёстко определяется `DataDirectory`, а БД открывается всегда в `init()`. Пользователь не может выбрать другое расположение БД или отключить автоматическое открытие.

## What Changes

- Новые пользовательские настройки: путь к файлу БД (пусто = путь по умолчанию из `DataDirectory`) и флаг «Открывать базу при запуске» (по умолчанию включён).
- Настройки сохраняются в файле конфигурации в пользовательском каталоге и читаются при запуске.
- Отдельное модальное окно настроек на JavaFX, открывается из меню «Файл → Настройки…» главного окна.
- Меню «Файл → Открыть базу» для ручного открытия БД, когда автооткрытие выключено.
- Меню «Файл → Создать базу…»: создание новой БД в выбранном месте с применением всех миграций из набора.
- При открытии существующей БД с устаревшей схемой пользователю предлагается применить миграции; без согласия БД не изменяется и не открывается.
- Перед миграцией создаётся резервная копия файла БД; при неудачной миграции БД восстанавливается из копии и показывается сообщение об ошибке миграции.
- Открытие БД переносится из `init()` в фоновую задачу после показа главного окна; при ошибке показывается сообщение, приложение не падает.

## Capabilities

### New Capabilities
- `app-settings`: хранение настроек БД (путь, автооткрытие) и окно их редактирования.

### Modified Capabilities
- `main-window`: новые пункты меню «Настройки…» и «Открыть базу»; БД открывается после показа окна согласно настройкам.
- `sqlite-persistence`: файл БД берётся из настроек; раздельные операции создания, открытия и миграции БД; обнаружение устаревшей схемы; резервная копия и откат при неудачной миграции.

## Impact

- Код: `MainWindowApp`, `persistence/Database` (разделение create/open/migrate, бэкап и восстановление), `persistence/DataDirectory`, новые классы настроек и окна настроек в `ru.onlychill.bonds2`.
- Тесты: юнит-тесты хранилища настроек и разрешения пути, создания БД, обнаружения устаревшей схемы, бэкапа и отката при сбое миграции; тест меню главного окна.
- Новых зависимостей нет (`java.util.Properties`, JavaFX controls уже подключены).
- Вне рамок: переключение «на лету» уже открытой БД на другой файл (новый путь применяется при следующем открытии/запуске), перенос данных между файлами, миграция вниз (downgrade); БД с версией схемы новее известной приложению не открывается.
