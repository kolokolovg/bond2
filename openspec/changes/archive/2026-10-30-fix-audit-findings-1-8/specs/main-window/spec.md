# Spec Delta

## MODIFIED Requirements

### Requirement: Пункт меню «Выход»
Строка меню SHALL содержать меню «Файл» с пунктом «Выход». Выбор пункта SHALL завершать приложение. Ожидание остановки сервиса БД SHALL NOT блокировать поток интерфейса, а повторный запрос выхода во время остановки SHALL игнорироваться. Сбой остановки после начала выхода SHALL NOT оставлять приложение незакрываемым: пользователю показывается ошибка, повторный запрос выхода обрабатывается заново.

#### Scenario: Выбор «Файл → Выход»
- **WHEN** пользователь открывает меню «Файл» и выбирает «Выход»
- **THEN** главное окно закрывается и процесс приложения завершается с кодом 0

#### Scenario: Закрытие окна штатным способом
- **WHEN** пользователь закрывает главное окно кнопкой закрытия окна
- **THEN** приложение завершается так же, как при выборе «Выход»

#### Scenario: Интерфейс отзывчив во время остановки
- **WHEN** пользователь выбирает «Выход», а открытие БД ещё не завершилось
- **THEN** поток интерфейса не блокируется ожиданием, приложение завершается после окончания остановки

#### Scenario: Повторный запрос выхода
- **WHEN** остановка уже началась и пользователь снова выбирает «Выход»
- **THEN** второй запрос игнорируется, остановка не запускается повторно

#### Scenario: Сбой цепочки выхода
- **WHEN** после начала выхода цепочка остановки завершается сбоем
- **THEN** показано сообщение об ошибке, приложение продолжает работать, повторный выбор «Выход» начинает выход заново

### Requirement: Пункты меню настроек и открытия БД
Меню «Файл» SHALL содержать пункты «Настройки…» (открывает окно настроек), «Открыть базу» (открывает БД по текущим настройкам), «Создать базу…» (создаёт новую БД в выбранном пользователем месте) и «Закрыть базу». Пункты «Открыть базу» и «Создать базу…» SHALL быть доступны только когда БД не открыта и не идёт миграция; «Закрыть базу» — только когда БД открыта. Отклонение создания из-за изменившегося состояния или начатой остановки SHALL показываться тихо, без диалога ошибки.

#### Scenario: Открытие окна настроек
- **WHEN** пользователь выбирает «Файл → Настройки…»
- **THEN** открывается модальное окно настроек

#### Scenario: Ручное открытие БД
- **WHEN** пользователь выбирает «Файл → Открыть базу»
- **THEN** БД открывается по пути из настроек

#### Scenario: Создание новой базы
- **WHEN** пользователь выбирает «Файл → Создать базу…» и указывает файл
- **THEN** по указанному пути создаётся БД с актуальной схемой, путь сохраняется в настройках, БД открывается

#### Scenario: Создание поверх существующего файла
- **WHEN** выбранный файл уже существует
- **THEN** БД не создаётся и существующий файл не изменяется; пользователю показывается сообщение

#### Scenario: Отклонение создания из-за гонки состояния
- **WHEN** создание БД отклонено из-за изменившегося состояния или начатой остановки, а не из-за ошибки файла
- **THEN** диалог ошибки не показывается, отклонение фиксируется в журнале
