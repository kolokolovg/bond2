# Spec Delta

## REMOVED Requirements

### Requirement: Настройки расположения БД
**Reason**: у приложения единственная БД — всегда файл в каталоге данных; настраиваемый путь и флаг автооткрытия не существуют.
**Migration**: не требуется. Путь к БД всегда определяется каталогом данных, открытие при запуске безусловно.

### Requirement: Хранение настроек
**Reason**: настроек расположения БД больше нет, хранить нечего; механизм платформенного хранилища удаляется из кода.
**Migration**: не требуется.

### Requirement: Редактирование настроек
**Reason**: окно настроек и пункт меню «Настройки…» удалены вместе с настройками.
**Migration**: не требуется.
