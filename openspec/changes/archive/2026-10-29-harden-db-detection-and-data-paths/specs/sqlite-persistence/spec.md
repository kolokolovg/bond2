## MODIFIED Requirements

### Requirement: Распознавание пустого и чужого файла
При открытии существующего файла система SHALL отличать пустой файл и файл SQLite без истории миграций приложения от БД приложения. Пустым SHALL считаться файл размером 0 байт либо корректный файл SQLite, в котором `sqlite_master` не содержит ни одной записи (таблиц, views, triggers, индексов, служебных `sqlite_*`), а `PRAGMA application_id` и `PRAGMA user_version` равны 0. Пустой файл SHALL инициализироваться актуальной схемой как новая БД, без предложения миграции. Файл SQLite, не имеющий истории миграций приложения и не являющийся пустым по этому определению, SHALL отклоняться ошибкой «не база данных приложения»; файл при этом SHALL NOT изменяться и миграция SHALL NOT предлагаться. Файл, не являющийся SQLite, отклоняется ошибкой чтения схемы, как и ранее.

#### Scenario: Пустой файл
- **WHEN** открывается существующий файл размером 0 байт
- **THEN** он инициализируется актуальной схемой, БД открывается без вопроса о миграции

#### Scenario: Чужая база SQLite
- **WHEN** открывается SQLite-файл с таблицами, но без истории миграций приложения
- **THEN** открытие завершается ошибкой «не база данных приложения», файл не изменён, миграция не предлагается

#### Scenario: Пустая база SQLite без таблиц
- **WHEN** открывается корректный SQLite-файл без объектов схемы: `sqlite_master` пуст, `application_id` и `user_version` равны 0
- **THEN** он обрабатывается как пустой: инициализируется актуальной схемой

#### Scenario: SQLite без таблиц, но с другими объектами
- **WHEN** открывается SQLite-файл без таблиц, но с view, trigger или индексом либо с таблицей `sqlite_stat1`
- **THEN** он отклоняется как «не база данных приложения», файл не изменён

#### Scenario: SQLite без объектов, но с заголовочными значениями
- **WHEN** открывается SQLite-файл без объектов схемы, у которого `application_id` или `user_version` не равен 0
- **THEN** он отклоняется как «не база данных приложения», файл не изменён

#### Scenario: Неудачная инициализация пустого файла
- **WHEN** инициализация пустого файла завершилась ошибкой
- **THEN** файл возвращается к пустому состоянию, а чужие данные затронуты быть не могли, так как такой файл не содержал объектов схемы

#### Scenario: База приложения
- **WHEN** открывается БД с историей миграций приложения
- **THEN** поведение прежнее: актуальная схема открывается, устаревшая требует миграции, новее приложения отклоняется

## ADDED Requirements

### Requirement: Каталог данных приложения
Система SHALL хранить файлы приложения (БД, настройки, файл блокировки) в каталоге `bonds2` внутри пользовательского каталога данных ОС: на Linux — `$XDG_DATA_HOME` (по умолчанию `~/.local/share`), на macOS — `~/Library/Application Support`, на Windows — `%LOCALAPPDATA%` (по умолчанию `~/AppData/Local`). Система SHALL NOT использовать каталог Roaming (`%APPDATA%`) и SHALL NOT переносить данные из него.

#### Scenario: Linux с абсолютным XDG_DATA_HOME
- **WHEN** `XDG_DATA_HOME` задан абсолютным путём
- **THEN** каталог данных — `bonds2` внутри этого пути

#### Scenario: Windows с LOCALAPPDATA
- **WHEN** `LOCALAPPDATA` задан абсолютным путём
- **THEN** каталог данных — `bonds2` внутри этого пути, а `%APPDATA%` не используется

#### Scenario: Windows без пригодного LOCALAPPDATA
- **WHEN** `LOCALAPPDATA` не задан, пуст или не абсолютен
- **THEN** каталог данных — `~/AppData/Local/bonds2`

#### Scenario: macOS
- **WHEN** приложение запущено на macOS
- **THEN** каталог данных — `~/Library/Application Support/bonds2`

### Requirement: Проверка переменных окружения каталога данных
Значение переменной окружения, задающей каталог данных (`XDG_DATA_HOME`, `LOCALAPPDATA`), SHALL использоваться, только если оно непустое, является корректным путём и абсолютно; иначе SHALL применяться значение по умолчанию для этой ОС.

#### Scenario: Относительный XDG_DATA_HOME
- **WHEN** `XDG_DATA_HOME` задан относительным путём
- **THEN** значение игнорируется, каталог данных — `~/.local/share/bonds2`

#### Scenario: Пустой или некорректный XDG_DATA_HOME
- **WHEN** `XDG_DATA_HOME` не задан, пуст, состоит из пробелов или не разбирается как путь
- **THEN** каталог данных — `~/.local/share/bonds2`

#### Scenario: Относительный LOCALAPPDATA
- **WHEN** на Windows `LOCALAPPDATA` задан относительным путём
- **THEN** значение игнорируется, каталог данных — `~/AppData/Local/bonds2`
