# Spec Delta

## ADDED Requirements

### Requirement: Исключительное владение файлом при служебных операциях
Служебные операции над файлом БД — создание новой БД, инициализация пустого файла, миграция с резервной копией — SHALL выполняться только при отсутствии открытого экземпляра БД для того же файла. При открытом экземпляре операция SHALL отказывать без изменения файла и каких-либо каталогов, а сообщение об ошибке SHALL называть файл. Открытие БД начинает владение файлом, закрытие — освобождает; после закрытия служебные операции допустимы.

#### Scenario: Миграция при открытом экземпляре
- **WHEN** существует открытый экземпляр БД для файла и запрашивается миграция с резервной копией этого файла
- **THEN** операция отказывает, файл и резервные копии не изменены, сообщение называет файл

#### Scenario: Инициализация при открытом экземпляре
- **WHEN** существует открытый экземпляр БД для файла и запрашивается инициализация этого файла
- **THEN** операция отказывает, файл не изменён, сообщение называет файл

#### Scenario: Операция после закрытия экземпляра
- **WHEN** экземпляр БД для файла закрыт и запрашивается служебная операция над этим файлом
- **THEN** операция выполняется по общим правилам, как будто открытого экземпляра не было
