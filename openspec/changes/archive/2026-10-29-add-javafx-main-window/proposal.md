# Proposal

## Why

Приложение пока консольное. Нужен графический интерфейс как основа для дальнейших экранов; первым шагом — главное окно с возможностью штатно завершить приложение через меню.

## What Changes

- Добавить зависимость OpenJFX (JavaFX) в Gradle-сборку (контролы, подключаемые через плагин/каталог версий).
- Добавить главное окно приложения с строкой меню.
- В меню «Файл» добавить пункт «Выход», завершающий приложение.
- Запуск приложения (`gradlew run`) открывает главное окно.
- **BREAKING**: консольный режим удаляется — `Main.run(...)` с разбором аргументов и вывод купонного платежа в консоль, вместе с `MainTest`. Расчёт купона (`Coupon`, `CouponMath`) остаётся как доменный код.

## Capabilities

### New Capabilities
- `main-window`: главное окно приложения со строкой меню и пунктом завершения работы.

### Modified Capabilities

## Impact

- `build.gradle.kts`, `gradle/libs.versions.toml`: плагин/зависимости JavaFX.
- `src/main/java/ru/onlychill/bonds2/`: новый класс JavaFX-приложения; `Main.main` запускает GUI, консольная логика `Main.run` удаляется; `MainTest` удаляется.
- Проверки качества (Error Prone/NullAway, SpotBugs, JaCoCo, PIT) должны продолжать проходить; UI-класс при необходимости исключается из мутационного тестирования.
