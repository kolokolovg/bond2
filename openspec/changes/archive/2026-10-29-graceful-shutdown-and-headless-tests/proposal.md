# Proposal

## Why

Если приложение завершается извне (Cmd+Q на macOS, завершение сессии ОС) во время открытия, создания или миграции БД, `shutdown()` не видит БД (она ещё не записана в контроллер), блокировка единственного экземпляра снимается раньше времени, а результат фоновой работы, пришедший позже, оставляет открытую `Database`, которую никто не закроет. Отдельно: UI-тесты (`FxBackgroundTest`, `MainWindowAppTest`, `SettingsDialogTest`) требуют дисплей, а CI на `temurin` его не имеет, поэтому они там не проходят.

## What Changes

- При завершении приложения контроллер БД ждёт окончания активной фоновой операции (с ограничением по времени), затем закрывает БД; блокировка экземпляра снимается только после этого.
- Результат фоновой операции, пришедший после начала завершения, не меняет состояние и не показывает диалогов; открытая им БД закрывается.
- Фоновый поток работы с БД перестаёт быть демоном, чтобы JVM не обрывала операцию.
- Порядок завершения «остановка контроллера, затем снятие блокировки» выносится в метод, проверяемый без JavaFX.
- UI-тесты выполняются без дисплея: сборка по флагу `-Pheadless=true` включает headless-режим JavaFX (Monocle) для задач `test` и `pitest`; CI использует JDK Liberica Full с JavaFX и этот флаг.
- README: убрать требование дисплея для тестов, описать флаг.

## Impact

- Код: `DatabaseController`, `FxBackground` (интерфейс `Background` получает дескриптор работы), `MainWindowApp.stop()`, тесты `DatabaseControllerTest`, `FxBackgroundTest`.
- Сборка: `build.gradle.kts` (`test`, `pitest`), `.github/workflows/ci.yml`, `README.md`.
- Зависимости не добавляются: Monocle берётся из JDK Liberica Full.
