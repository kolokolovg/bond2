## MODIFIED Requirements

### Requirement: Сохранение настроек
Система SHALL сохранять настройки в файле конфигурации в пользовательском каталоге и восстанавливать их при следующем запуске. Повреждённый или нечитаемый файл настроек SHALL NOT мешать запуску: применяются значения по умолчанию (см. «Восстановление испорченного файла настроек»).

#### Scenario: Перезапуск
- **WHEN** пользователь сохранил настройки и перезапустил приложение
- **THEN** сохранённые значения применены

#### Scenario: Повреждённый файл настроек
- **WHEN** файл настроек не удаётся разобрать
- **THEN** приложение запускается со значениями по умолчанию

## ADDED Requirements

### Requirement: Восстановление испорченного файла настроек
Система SHALL молча копировать испорченный файл настроек в `settings.properties.bad-<yyyyMMdd-HHmmss>` рядом с ним, записывать на его место значения по умолчанию и применять их. Испорченным считается файл, который не читается или содержит значения, не разбираемые как путь к БД (только абсолютный) и флаг `true`/`false`. Отсутствие файла, ключей и пустой путь повреждением SHALL NOT считаться. Сбой копирования или записи не мешает запуску и пишется в лог.

#### Scenario: Файл настроек не читается
- **WHEN** файл настроек не удаётся разобрать
- **THEN** его копия сохранена как `settings.properties.bad-<метка времени>`, файл настроек содержит значения по умолчанию, приложение запускается с ними

#### Scenario: Относительный путь к БД
- **WHEN** в файле настроек путь к БД относительный
- **THEN** файл копируется и сбрасывается, как повреждённый, и открывается БД по умолчанию

#### Scenario: Неверное значение флага
- **WHEN** флаг автооткрытия равен значению, отличному от `true` и `false`
- **THEN** файл копируется и сбрасывается, как повреждённый

#### Scenario: Первый запуск не считается повреждением
- **WHEN** файла настроек нет или в нём нет части ключей
- **THEN** копия не создаётся, отсутствующие значения берутся по умолчанию

#### Scenario: Копию создать не удалось
- **WHEN** копирование или запись значений по умолчанию завершились ошибкой
- **THEN** приложение запускается со значениями по умолчанию, ошибка записана в лог
